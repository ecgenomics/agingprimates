# Data dictionary

This document describes the fields generated by `build_longevity_quotient.py`.

## `longevity_quotient.tsv`

| Field | Meaning |
|---|---|
| `accepted_tree_tip` | Candidate species identifier in `Genus_species` format. Consult `taxonomic_mapping_status` before treating it as an accepted tree tip. |
| `original_species_name` | Species name parsed from the original phenomic `GroupName`, retained for traceability. |
| `superfamily` | Superfamily or broad primate-group code parsed from `GroupName`. |
| `family` | Taxonomic family parsed from `GroupName`. |
| `MLS_years` | Observed maximum lifespan in years, from trait `PTD00065`. |
| `body_mass_g` | Adult body mass in grams, converted from the original `PTD00014` value in kilograms. |
| `expected_MLS_years` | Mammal-wide allometric expectation: `6.47 × body_mass_g^0.189`. |
| `LQ_mammal` | `MLS_years / expected_MLS_years`. One is the allometric expectation; values above or below one denote longer- or shorter-than-expected lifespan. |
| `log_LQ_mammal` | `ln(MLS_years) − ln(expected_MLS_years)`, equivalently `ln(LQ_mammal)`. Zero is the expectation. This is the recommended continuous modelling scale. |
| `MLS_trait_id` | Maximum-lifespan source trait identifier (`PTD00065`). |
| `MLS_source` | Bibliographic provenance supplied for maximum lifespan. |
| `MLS_source_link` | Source URL supplied for maximum lifespan. |
| `mass_trait_id` | Body-mass source trait identifier (`PTD00014`). |
| `mass_source` | Bibliographic provenance supplied for body mass. |
| `mass_source_link` | Source URL supplied for body mass. |
| `taxonomic_mapping_status` | `exact_tree_tip_match` for an exact match in the Kuderna S4 tree; otherwise `not_in_tree_exactly`, requiring reconciliation before phylogenetic analysis. |
| `genome_samples` | Number of mapped genomic samples. This annotation is not used as a phenotype inclusion filter. |
| `genome_available` | Boolean indicating whether `genome_samples > 0`. |

All logarithms are natural. `LQ_mammal` is the historical replication trait;
`log_LQ_mammal` contains the same information on a scale symmetric around the
allometric expectation.

## `longevity_quotient_audit.tsv`

The audit contains every phenomic input record, including excluded records.

| Field | Meaning |
|---|---|
| `original_group_name` | Complete source `GroupName` before parsing. |
| `superfamily`, `family`, `original_species_name`, `accepted_tree_tip` | Taxonomic fields defined above. |
| `original_MLS_value` | Unmodified `PTD00065` value. |
| `original_MLS_unit` | Source MLS unit (`years`). |
| `MLS_years` | Numeric MLS standardized to years. |
| `original_body_mass_value` | Unmodified `PTD00014` value. |
| `original_body_mass_unit` | Source mass unit (`kg`). |
| `body_mass_g` | Numeric body mass standardized to grams. |
| `taxonomic_mapping_status` | Exact-string tree-match result defined above. |
| `MLS_trait_id`, `MLS_source`, `MLS_source_link` | MLS provenance. |
| `mass_trait_id`, `mass_source`, `mass_source_link` | Body-mass provenance. |
| `source_access_date` | Access date, or an explicit statement that it was absent from the supplied metadata. |
| `captive_wild_context` | Captive/wild context, or an explicit statement that it was absent. |
| `sex` | Sex context, or an explicit statement that it was absent. |
| `sample_size` | Observation sample size, or an explicit statement that it was absent. |
| `duplicate_resolution_rule` | Duplicate-resolution rule; none was needed because current `GroupName` values are unique. |
| `included` | `True` when MLS and body mass are both finite and strictly positive. |
| `exclusion_reason` | Reason an excluded row lacks a computable LQ; empty for included rows. |

## Other generated files

- `build_report.json` records formula, input checksums, inclusion and exclusion
  counts, tree matches, genome availability, and historical comparison.
- `longevity_quotient.tsv.md5` is the checksum of the main dataset.
- `MD5SUMS` contains checksums for the dataset, audit, and build report.
