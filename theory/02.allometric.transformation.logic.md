# Logic of the allometric transformation

## Purpose

Maximum lifespan (MLS) increases with body size across mammals. Raw MLS is
therefore not a direct measure of whether a species lives longer than expected
for its size. The working phenotype must separate exceptional longevity from
the predictable allometric component associated with adult body mass.

The historical project used a longevity quotient (LQ): observed maximum
lifespan divided by the maximum lifespan expected for a mammal of the same body
mass. An LQ of 1 denotes the allometric expectation, values above 1 denote
longer-than-expected lifespan, and values below 1 denote shorter-than-expected
lifespan.

## What was already done in this repository

The implementation is in `fetchaging.py`. It did **not** estimate a regression
from the primate observations. It applied the following fixed mammalian
equation directly:

```text
expected_MLS_years = 6.47 × body_mass_g^0.189
LQ = observed_MLS_years / expected_MLS_years
```

The script attributes this equation to de Magalhães, Costa, and Church (2007).
The same general observed/expected LQ framework was used by Farré et al. (2021)
for the mammalian comparative genomic analysis that this project updates.

### Historical input files and fields

1. `inputs/nhp.phenomic.dataset.csv`
   - one row per phenomic group/species;
   - `GroupName` encodes superfamily, family, genus, and species;
   - `PTD00065` is selected as `Maximum.lifespan..y.`;
   - `PTD00014` is selected as `BodyMass_kg`;
   - `PTD00001`, labelled `Body_mass`, was also loaded but not used in the LQ
     calculation.
2. `inputs/mls.traits.manual.tab`
   - maps `PTD00065` to `Maximum.lifespan..y.`.
3. `inputs/bm.traits.manual.tab`
   - maps `PTD00001` to `Body_mass` and `PTD00014` to `BodyMass_kg`.
4. `inputs/trait.data.sources.csv`
   - attributes `PTD00065` to Van Schaik/Isler and AnAge;
   - attributes `PTD00014` to Galán-Acedo et al. (2019).
5. `inputs/tmb.sample.count.tab`
   - maps species names to genomic sample counts;
   - the historical pipeline retained only species with at least one genomic
     sample after calculating LQ.

### Historical processing sequence

1. Select `GroupName`, MLS, and both candidate body-mass fields.
2. Parse `GroupName` into superfamily, family, and species.
3. Convert `BodyMass_kg` to grams by multiplying by 1,000.
4. Calculate expected MLS with the fixed equation.
5. Calculate LQ as observed MLS divided by expected MLS.
6. Remove observations lacking a computable LQ.
7. Calculate a global LQ z-score, although it was later dropped from the final
   table.
8. Map genomic sample counts and retain species with `GenomeSamples > 0`.
9. Calculate family-specific mean, standard deviation, and z-score, although
   only the family mean was retained in the final table.
10. Generate binary configurations for long- and short-lived species.

The current final historical table contains 140 species with complete MLS,
body mass, computable LQ, and genomic availability.

## Problems and ambiguities in the historical implementation

### Trait provenance is not carried into the output

The final table contains values but no per-observation source, access date,
original unit, uncertainty, captive/wild status, sex, sample size, or rule used
to resolve duplicates. These must be preserved in the reconstruction.

### Two body-mass traits are selected but only one is used

`PTD00001` and `PTD00014` are loaded, but the equation uses only
`BodyMass_kg` (`PTD00014`). We must verify why this source was preferred, its
coverage, and whether it represents adult mass consistently across species.

### Taxon parsing is brittle

The species label is constructed from fixed underscore-separated positions in
`GroupName`. This assumes a rigid four-part format and does not document name
changes. Trait names must instead be reconciled explicitly to the 236 Kuderna
S4 tips.

### The fitting population is external to the primate dataset

The constants 6.47 and 0.189 encode a mammal-wide relationship. That is useful
for comparability with Farré et al. (2021), but it is not the same question as
asking whether a primate is long-lived relative to other primates. Both
interpretations should be calculated and kept distinct.

### Phylogeny is not used in the fixed equation

The historical LQ calculation is an arithmetic transformation. Shared ancestry
does not enter the estimation of the expected lifespan. Phylogenetic signal was
tested only after LQ had been calculated.

### Thresholds are inconsistent with their comments

The code comments describe long-lived species as `LQ > 1.5` and short-lived
species as `LQ < 0.5`, while the executable code uses `LQ > 1.3` and
`LQ < 0.7`. These thresholds are downstream classification decisions, not part
of the allometric correction, and must be reconsidered independently.

### Filtering can change summaries

Family means are calculated only after filtering for genomic availability.
Thus they describe the sequenced subset rather than the phenotypic population.
Phenotype construction and genome filtering should be separated.

## Proposed reproducible reconstruction

### Stage 1: freeze and audit raw observations

Create a long-form audit table containing at least:

- accepted tree tip;
- original species name;
- original MLS value and unit;
- standardized MLS in years;
- original mass value and unit;
- standardized adult mass in grams;
- source and access date for each value;
- captive/wild context where available;
- taxonomic mapping status;
- inclusion/exclusion status and reason.

Do not use genome availability to decide which phenotypic observations are
valid at this stage.

### Stage 2: define the primary fixed-formula trait

For every species with valid positive MLS and mass:

```text
log_expected_MLS = log(6.47) + 0.189 × log(body_mass_g)
expected_MLS_years = exp(log_expected_MLS)
LQ_mammal = observed_MLS_years / expected_MLS_years
log_LQ_mammal = log(observed_MLS_years) - log_expected_MLS
```

The log form is algebraically equivalent but more numerically transparent.
`LQ_mammal` should be the primary replication trait because it preserves
comparability with the earlier workflow. `log_LQ_mammal` is recommended for
model fitting because it is symmetric around zero and is exactly the residual
from the fixed log-log relationship when the coefficients are held constant.

Required checks include positive finite inputs, explicit kg-to-g conversion,
hand-calculation of several species, missing-value accounting, and comparison
with the historical `dataset/lqdf.tab` for overlapping taxa.

### Stage 3: fit a primate-specific sensitivity model

Using only reconciled primate species with complete traits, fit:

```text
log(MLS_years) = alpha + beta × log(body_mass_g) + error
```

Fit at least:

1. ordinary least squares, as a descriptive benchmark;
2. phylogenetic generalized least squares (PGLS) on the pruned Kuderna S4 time
   tree, estimating an appropriate phylogenetic covariance parameter such as
   Pagel's lambda.

The preferred primate-specific corrected trait is the PGLS residual, provided
model diagnostics are satisfactory. Record the fitted alpha, beta, lambda,
sample size, taxa, likelihood, uncertainty intervals, residual diagnostics,
and exact tree checksum. Do not call these residuals the historical LQ; use a
distinct name such as `PGLS_logMLS_residual`.

### Stage 4: compare trait definitions

Compare `LQ_mammal`, `log_LQ_mammal`, OLS residuals, and PGLS residuals using:

- rank and Pearson/Spearman correlations;
- changes in the top and bottom species;
- clade/family distributions;
- influence diagnostics;
- remaining phylogenetic signal;
- robustness to alternative mass or MLS sources.

The comparison should determine whether downstream CAAS and RERconverge
conclusions depend on the allometric definition.

### Stage 5: estimate phylogenetic signal

After pruning the Kuderna S4 tree to each complete trait set and enforcing an
exact one-to-one match between tips and observations, estimate phylogenetic
signal separately for:

- `log(MLS_years)`;
- `log(body_mass_g)`;
- `LQ_mammal` and/or `log_LQ_mammal`;
- `PGLS_logMLS_residual`.

At minimum report Pagel's lambda and Blomberg's K with confidence intervals or
permutation/likelihood tests, sample size, and tree pruning audit. Comparing the
raw and corrected traits tells us how much phylogenetic structure remains after
body-mass correction.

## Primary and sensitivity decisions

The proposed analysis hierarchy is:

- **Primary replication:** fixed mammal-wide equation and `LQ_mammal`, matching
  the previous project logic.
- **Primary modelling scale:** `log_LQ_mammal` where a continuous approximately
  symmetric response is preferable.
- **Sensitivity analysis:** primate-specific PGLS residual using Kuderna S4.
- **Downstream binary contrasts:** defined only after trait construction and
  diagnostics; no historical cutoff is accepted automatically.
