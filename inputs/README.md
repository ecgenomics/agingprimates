# Analysis inputs

This directory is the independent input collection for the primate aging
update. Results from previous analyses are not treated as inputs and will be
reintroduced only after they have been reviewed.

## Primary phylogenetic tree

`science.abn7829_data_s4.nex.tree` is an unchanged local copy of:

`traits.evolution.omar/score.approach/inputs/tree/science.abn7829_data_s4.nex.tree`

The tree is Supplementary Data S4 from Kuderna et al. (2023), *A global
catalog of whole-genome diversity from 233 primate species*, Science 380,
906–913, DOI: 10.1126/science.abn7829.

It is a plain Newick tree despite the `.nex.tree` extension of the source. It
contains 236 tips and is rooted, fully bifurcating, fossil-calibrated, and
ultrametric. Branch lengths represent evolutionary time (approximately Ma).

The original Kuderna filename is retained deliberately so that the selected
tree cannot be confused with the former project tree. Its integrity checksum
is stored in `science.abn7829_data_s4.nex.tree.md5`.
